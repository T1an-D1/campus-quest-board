# 字段口径

录入一条委托时，信息多半来自一张通知截图或一段群里发的文字。这份文档说明：通知里的常见说法，对应到委托的哪个字段，以及容易看错的地方。

## 对照表

| 通知里的原话 | 对应字段 | 注意 |
|---|---|---|
| “11 月 20 日 14:00–17:00” | 开始时间 / 结束时间 | 跨零点的活动（如 22:00–次日 1:00）按结束时间落在次日处理 |
| “需连续参加 3 天” | 连续天数 | 只写了一次日期却说“连续”，以文字为准；没有写就按 1 天 |
| “每场 3 小时” | 单场时长 | 与开始/结束时间不一致时，以时间差为准，人工核对 |
| “招募 30 人，已报 27 人” | 名额上限 / 已报名 | 只给“还剩 3 个名额”时，上限按已报 + 剩余反推，口径写进备注 |
| “可获 PU 学分（社会实践类）2 分” | PU 学分类型 / PU 学分数 | 类型决定加权系数，写错类型等于算错分；只写“PU 学分”未写类型时按其他类处理 |
| “志愿时长 6 小时” | 志愿时长 | 培训时长通常不计入志愿时长，只在成本里算 |
| “活动结束发证书” | 是否有证书 | “优秀志愿者证书”这类要评比的，按无证书处理，避免高估 |
| “提供午餐 / 物资” | 是否有物资 | 只发水不算物资 |
| “需面试” | 需要面试 | 线上面试同样算，成本加 0.75 小时 |
| “需参加岗前培训” | 需要培训 | 培训成本固定按 1 小时 |
| “需具备摄影 / 急救等技能” | 需要技能 | 招“有经验者优先”不算硬性技能 |
| “8:00 前到场” | 早起 | 开始时间早于 08:00 自动判定，无需单独勾 |
| “请着正装 / 制服” | 对着装要求 | 统一发的马甲不算着装要求 |
| “限大一、大二” | 参与资格 | 与本人年级冲突时，诉求匹配 −32 |
| “线上进行” | 区域 = 线上 | 通勤按 0 计，匹配度 +8 而不是 +10 |

## 三条容易出错的口径

1. **时间重叠按区间算，不按整点算。** 14:00–17:00 与 16:30–18:00 重叠半小时，也算撞车。宁可判冲突，不要放过。
2. **名额占用率用四舍五入前的原值。** 29/30 是 96.7%，不是 100%，但都触发“≥ 90%”的难度加分。
3. **“可获”与“已获”要分清。** 通知里的“可获 PU 学分”是奖励承诺，只有在“我的日程”里标记完成后，才计入 PU 进度。

## 批量导入格式

竖线分隔，14 段，一行一条：

```
类型|区域|开始时间|结束时间|连续天数|单场时长|名额上限|已报名|要求|PU类型|PU学分|志愿时长|证书|物资
```

要求一栏可以写多项，用逗号分隔，例如 `面试,体力`。缺项可以留空，但管道符数量必须对，否则整行会被跳过。
